# Known limitations and test status

- The quality changes use vanilla-scale game judgements, with explicit historical uncertainty. They are not measured historical percentages.
- National command presets are retained. The separate raw command fields do not have a verified seconds equation.
- Offline hashes, XML audits and native imports do not establish full in-game behaviour. Loading, firing, towing, transport, animation, morale and performance acceptance must be recorded for the exact tested revision.
- Latest quality validation reported zero database errors and 1,501 inherited warnings. Review warning changes; do not suppress them merely to obtain a clean count.
- Historical unit/model approximations remain documented in their records. Generic scouts/sappers do not automatically receive elite bonuses.
- Some moving infantry appearance is shared nationally/by date. Distinct unit-specific moving uniforms are not a demonstrated supported capability in this project.
- Custom maps are withdrawn and custom scenery remains unused. Neither is part of this unit-only candidate.
- Original model-generation scripts depend on local inputs and are not a reproducible clean-machine build. The committed payload can be verified and packaged with the maintained standard-library tools.
- The sole Fort Irwin scenario is a diagnostic fixture, not a complete gameplay test suite.
